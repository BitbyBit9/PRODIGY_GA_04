## Task-04: Chatbot using NLP (Code)

This folder contains the implementation of a **rule-based chatbot** developed as part of Task-04 of the Generative AI Internship at Prodigy InfoTech.

### 📌 File Description
- **chatbot.py**  
  Python script that implements a simple chatbot using predefined intents and keyword-based matching.

### 🧠 Approach Used
- Rule-based intent recognition
- Keyword matching for NLP
- Predefined responses for each intent
- Continuous conversation loop
- Chat logging for output storage

### 🛠️ Technologies Used
- Python
- Basic Natural Language Processing (NLP)
- Dictionaries and conditional logic

### 🎯 Objective
To understand the fundamentals of conversational AI by building a chatbot without using complex machine learning models.
