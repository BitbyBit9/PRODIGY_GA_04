# Task-04: Chatbot using NLP

This project was developed as part of **Task-04** of the **Generative AI Internship at Prodigy InfoTech**.

## 📌 Project Overview
The objective of this task is to design and implement a **simple chatbot** using basic Natural Language Processing techniques. The chatbot identifies user intent using predefined rules and responds accordingly.

## 🧠 Methodology
- User input is processed and converted to lowercase
- Keyword-based matching is used to identify intent
- Predefined responses are generated for matched intents
- A conversation loop enables continuous interaction
- The entire conversation is saved in a text file

## 🛠️ Technologies Used
- Python
- Rule-Based NLP
- File Handling

## 🎯 Outcome
The chatbot successfully interacts with users, responds to basic queries, and stores the conversation in an output file, demonstrating a foundational understanding of conversational AI.
